# 奶蛙乐园：午夜奶片

**Milk Frog Park: Midnight Milk Candy**

> 第一人称、温馨又惊悚的 3D 迷宫游戏。在废弃的「奶蛙乐园」收集八片奶片，躲开一直跟着你的奶蛙，从安全出口离开。

技术栈 **HTML / CSS / JavaScript + Three.js**；无构建、无后端、可离线运行；运行时依赖 Python 3 静态服务器。

## 1. 目的与控制方式

### 1.1 目的

Week 05 小组作业《3D Game》的可运行源码。儿童乐园装潢与追击型奶蛙、意识值、幻觉构成「温馨又惊悚」的反差体验。单关卡，单局 3–6 分钟，面向 PC 键鼠玩家的独立小游戏。几何、贴图与音频全部本机生成，不依赖 CDN、账号或密钥。

奶蛙形象是网络迷因（被魔改的「奶龙」表情包）的同人二创，不使用官方素材。

### 1.2 一局怎么玩

1. 找到 **8 片奶片**（贴地发光的圆片）。
2. 集满 **3 片** → 解锁 **乐园地图**（左下角小地图）。
3. 集满 **6 片** → 解锁 **加速 / 糖分**（SHIFT 冲刺）。
4. 集满 **8 片** → 出口厅的 **安全出口** 打开。
5. 走到出口前按 **E** → 通关。

奶蛙：

- 4 只，3 种体型（小奶蛙 / 胖奶蛙 / 长腿奶蛙），游荡并追人；被玩家主动逼近时后退。
- 身体为组员提供的 `assets/models/nailong_colored_2.0.glb`（原创静态网格，无骨骼）；加载失败时回退为程序化奶蛙。
- 正常速度下追不上也甩不掉；玩家静止或被堵住时会被贴身，判定失败；冲刺可让它们短暂眩晕。
- 距离越近，「我是奶龙！我才是奶龙！」越响，心跳与红色暗角越重。

失败进入「你被找到了」结算页；ESC 暂停可继续 / 重新开始 / 返回主菜单；重开清空本局进度。

### 1.3 意识值与龙奶

- 从 100% 起随时间下降（幻觉期间暂停），约 2 分钟归零；暂停或窗口失焦时停止计时。
- 低于 20% 与 10% 各触发一次幻觉（画面 7 秒、音效 8 秒），归零即失败；幻觉不影响操作。
- 降至 50% 时地图随机出现 3 瓶龙奶，靠近自动拾取，每瓶 +20%，冷却 10 秒，不显示在小地图上。

### 1.4 演示模式（Demo）

主菜单 **「演示模式 / DEMO」**：脚本操作真实游戏自动游玩约 2.5 分钟（24 片奶片，142–157 秒通关），结束显示胜利结算并回主菜单，ESC 可退出。场景、HUD、AI、声音与胜负逻辑与真人相同。

## 3. 本地运行与发布

### 3.1 本地运行

```bat
cd <本目录>
python serve.py 8000
```

入口 http://127.0.0.1:8000/；Windows 下等价入口为 `run_game.bat`。Three.js 0.160.0 已放在 `vendor/three.module.js`，运行时不联网。

### 3.2 发布到 GitHub Pages

静态托管，无构建步骤。

| 设置项    | 取值                   |
| ------ | -------------------- |
| Source | Deploy from a branch |
| Branch | `main`               |
| Folder | `/`（root）            |

GitHub Pages 为 Linux 静态托管，文件名区分大小写；页面经 CDN 缓存。

### 3.3 打包运行包

```bat
python tools/package_submission.py
```

产物为 `release/w05_3d_game/`（源码、`vendor/`、`assets/`、依赖清单与 README，相对路径不变），不含 `node_modules/`、`tools/`、`release/`。

## 4. 已知限制

**玩法**

- 单关卡；「震荡 / 磁铁」未实现。
- 无存档，只有音量与静音写入 localStorage。
- 仅桌面键鼠，无手柄与移动端。

**画面**

- 程序化低多边形风格；低端显卡与软件渲染下帧率下降。
- 奶蛙为静态 GLB 模型，无骨骼动画，行走靠整体摇摆。
- 场景仍有建模重叠、局部错位与贴图接缝；片头镜头偶有轻微穿模，切到可操作较生硬。
- 个别区域（午睡室、出口厅）偏暗，贴图未做人眼终审。

**音频**

- 旁白与奶蛙音效未做人耳终审，音量平衡可能需微调。
- `frog_voice_1` 来自 Bilibili 音频裁剪；`assets/audio/nai_long.mp3` 游戏内未播放但仍随 manifest 预加载（约 0.56 MB）。公开分发前需确认授权或移除。
- 本地 Windows TTS 会把 SSML 音高量化，语速只有固定档位。

**运行环境**

- 直接以 `file://` 打开 `index.html` 无法运行：ES Module 与 `fetch()` 被浏览器拦截。需经 HTTP 静态服务访问。
- 浏览器自动播放策略要求首次交互后才出声。
- Pointer Lock 在个别系统上首次点击可能不生效。
- 自动化验收为 Microsoft Edge (Chromium) headless + Playwright Core，三档分辨率；Chrome / Edge 桌面版预期可用，Firefox / Safari 未测。验收用 SwiftShader 软件渲染，只覆盖「能运行、无报错、流程可走通」。
- 内部通道扫描为几何近似，复合道具需显式标 `userData.channelFloatOk` 才不误报。

**发布与部署**

- GitHub Pages 为 Linux 静态托管、**不运行任何后端**；本游戏无服务端逻辑，可部署到 Pages，但任何需要服务器或接口的能力都无法在 Pages 上运行。
- 页面经 CDN 缓存，仓库更新后线上需**数分钟**才生效；验证前应先确认部署已完成，必要时强制刷新。
- 首屏加载约 **9.3 MB 音频**（27 条 WAV），弱网或低配设备下加载较慢；本项目仅面向桌面键鼠，未做移动端适配。
- 仅「部署成功」或「自动化验收通过」**不代表游戏可玩**：自动化只覆盖「能运行、无报错、流程可走通」，开始 / 操作 / 进度 / 重启 / 声音与免登录打开仍需真人验证。
- 公开分发前需确认 `frog_voice_1` 人声授权，并处理随 manifest 预加载的 `assets/audio/nai_long.mp3`（约 0.56 MB，游戏内未播放）。
