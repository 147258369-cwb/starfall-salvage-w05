# 场景摆放静态审计 — 悬空 / 穿模 / 位置异常

审计对象：`src/world.js`（1201 行）+ `src/config.js`（132 行）
审计方式：静态推算（坐标换算 + 包围盒几何）+ 内部通道运行时扫描复核
本报告全部坐标均为**世界坐标**（米），格子坐标写作 (cx,cz)。世界坐标 = (格子 + 0.5) x 3.2。

> 说明：本轮由 AI 编码助手完成静态推算，运行时扫描结果来自 `src/inspect.js` 的内部通道。
> 尚未做真人试玩确认——哪些问题在游戏内"看起来明显"仍需人眼判断。

---

## 0. 结论摘要

共 **14 项**问题，其中 **10 项系统性/区域级**（会影响多个物件），**4 项单体**。

| 级别 | 数量 | 说明 |
|---|---|---|
| 严重 | 7 | 玩家走到附近抬头就能看见，属于明显穿帮 |
| 中等 | 5 | 需要特定角度或近距离才注意到 |
| 轻微 | 2 | 数值偏差，构图/比例问题 |

四类根因：

1. **单位混用**：`addBox/addCyl/addPoster` 收世界坐标，`addTable/addChair/addBed` 收格子坐标；调用点把 `cx * C` 直接传给世界坐标接口，少加了 0.5 格（=1.6 m）。
2. **家具拼装时腿和面不是同一套坐标**：长椅、摇椅、台灯的腿/靠背用了另一套偏移，导致腿飘在座面外、靠背和座面分离。
3. **高度算错半高**：`addBox(w,h,d,...y)` 的 y 是几何中心。
4. **贴墙物件少减了自身厚度**：海报先按"离墙 0.19 m"算好，`addPoster` 内部再 `translateZ(0.045)`，最终离墙 0.24 m。
